About this page

빠르게 만들고, 실제 결과로 검증하는 개발자

한결은 반복적인 규제 대응 업무를 더 나은 소프트웨어 경험으로 바꾸기 위해, AI를 활용하되 판단과 검증은 직접 책임지는 개발자입니다.

Three things I practice

상황에서 드러난 세 가지

운영까지 책임지는 제작

상황: 약 10년 전 모바일 마인크래프트 서버가 필요했습니다. 행동: PocketMine-MP 기반 플러그인을 직접 개발하고 서버를 운영했습니다. 결과: 한국 내 모바일 마인크래프트 서버 중 1위 규모에 도달했습니다.

속도와 검증을 함께 두는 개발

상황: 규제 대응 서류를 자동 분류하는 로직에서 서로 다른 시점의 결과가 갈렸습니다. 행동: 표준 라이브러리 구현과 식별자 매칭 결과를 실제 데이터로 대조해 하나로 합쳤습니다. 결과: 검증한 판정 로직을 남기고, 완료·미완료 범위를 v0.1~v0.12 문서로 구분했습니다.

반복 업무를 제품으로 바꾸기

상황: 기업의 반복적인 규제 대응 업무에는 수작업이 남아 있습니다. 행동: Node.js(Express)와 Python으로 백엔드를 설계하고 클라우드에 배포해 운영하고 있습니다. 결과: 서류·견적 처리 자동화를 목표로 하는 시스템이 실제 운영 환경에서 이어지고 있습니다.

근거 상태

공개 검증 자료는 아직 없습니다

위 경험의 커밋 이력과 버전 문서는 내부 작업물이라 공개하지 않습니다. 확인 가능한 공개 URL을 확보하기 전까지는, 외부 근거가 있는 것처럼 보이게 하지 않겠습니다.

이 선택의 의미 보기

현재 페이지는 경험의 범위와 공개 경계를 소개합니다. 향후 공개 가능한 저장소 또는 문서가 생기면, 이 영역에 출처와 함께 연결할 예정입니다.

공개하지 않는 범위

작업은 보이되, 민감한 정보는 남기지 않습니다

  • 실명, 연락처, 위치 같은 개인 식별 정보
  • 고객사명과 내부 업무 프로세스
  • 비밀번호, API 키, 비공개 저장소와 원문 문서
