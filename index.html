Three things I practice

상황에서 드러난 세 가지

운영까지 책임지는 제작

상황: 약 10년 전 모바일 마인크래프트 서버가 필요했습니다. 행동: PocketMine-MP 기반 플러그인을 직접 개발하고 서버를 운영했습니다. 결과: 한국 내 모바일 마인크래프트 서버 중 1위 규모에 도달했습니다.

속도와 검증을 함께 두는 개발

상황: 규제 대응 서류를 자동 분류하는 로직에서 서로 다른 시점의 결과가 갈렸습니다. 행동: 표준 라이브러리 구현과 식별자 매칭 결과를 실제 데이터로 대조해 하나로 합쳤습니다. 결과: 검증한 판정 로직을 남기고, 완료·미완료 범위를 v0.1~v0.12 문서로 구분했습니다.

반복 업무를 제품으로 바꾸기

상황: CPNP·PPWR 등 화장품·포장재 규제 대응 업무에 반복적인 서류·견적 처리가 남아 있었습니다. 행동: Node.js(Express)+PostgreSQL+Prisma 기반 제출 포털(파일 업로드, 인증, 요청 제한)과 Python 기반 문서 판정 엔진, 규칙 기반 파서+LLM 폴백 견적 시스템을 설계해 Railway에 배포했습니다. 결과: 데이터 영속성과 접근 제어를 갖춘 시스템이 실제 운영 환경에서 이어지고 있습니다.
